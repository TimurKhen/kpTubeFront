Client-side video hosting platform built with **Angular**, **SCSS**, and **RxJS**.

# **🚀 Key Features**

* **Video Streaming & Player**: Custom `video-player` component with fullscreen and Picture-in-Picture support.  
* **User Authentication**: Secure JWT-based authentication and account management.  
* **Video Management**: Interfaces for uploading videos, setting custom thumbnails, titles, and descriptions.  
* **Custom UI Components**: In-app notifications and alerts (`alert`, `prompt`).  
* **REST API Integration**: Modular HTTP services using Angular `HttpClient` and `HttpHeaders`.

# **🛠️ Tech Stack**

* **Framework**: Angular  
* **State & Streams**: RxJS  
* **Styling**: SCSS / SASS  
* **Language**: TypeScript

# **🔧 Local Development**

1. Clone the repository:

git clone https://github.com/TimurKhen/kpTubeFront.git

cd kpTubeFront

2. Install dependencies:

npm install

3. Run the development server:

ng serve

Navigate to `http://localhost:4200/`.
